CẤU HÌNH MẪU

Chọn công cụ đang sử dụng

Các ví dụ không chứa API key thật và có thể sao chép để chỉnh sửa.

OpenClaw

Thêm custom provider vào openclaw.json, sau đó chọn model thuộc provider token-codex.

  • Giữ key trong biến môi trường TOKEN_CODEX_API_KEY.
  • Khởi động lại OpenClaw sau khi đổi cấu hình.
{
  "models": {
    "providers": {
      "token-codex": {
        "baseUrl": "https://codex.anhlaptrinh.vn/v1",
        "apiKey": "${TOKEN_CODEX_API_KEY}",
        "api": "openai-completions",
        "models": [
          {"id": "GPT-5.6-sol", "name": "GPT-5.6-sol"},
          {"id": "GPT-5.6-terra", "name": "GPT-5.6-terra"},
          {"id": "GPT-5.6-luna", "name": "GPT-5.6-luna"}
        ]
      }
    }
  }
}

Codex trong Antigravity

Cấu hình Codex CLI/extension trong file người dùng %USERPROFILE%\.codex\config.toml.

  • env_key là tên biến môi trường, không phải API key thật.
  • Có thể đổi dòng model sang GPT-5.6-terra hoặc GPT-5.6-luna.
  • Restart Antigravity hoặc Codex sau khi lưu.
config.toml
model_provider = "token_codex"
model = "GPT-5.6-sol"

[model_providers.token_codex]
name = "Token Codex"
base_url = "https://codex.anhlaptrinh.vn/v1"
env_key = "TOKEN_CODEX_API_KEY"
wire_api = "responses"
PowerShell
[Environment]::SetEnvironmentVariable(
  "TOKEN_CODEX_API_KEY",
  "YOUR_TOKEN_CODEX_API_KEY",
  "User"
)

Hermes Agent

Dùng endpoint tương thích OpenAI và chọn một trong ba model được chấp nhận.

  • Ví dụ mặc định dùng GPT-5.6-sol.
  • Có thể đổi sang GPT-5.6-terra hoặc GPT-5.6-luna.
  • Không commit file chứa biến môi trường.
export OPENAI_API_KEY="YOUR_TOKEN_CODEX_API_KEY"
export OPENAI_BASE_URL="https://codex.anhlaptrinh.vn/v1"
export OPENAI_MODEL="GPT-5.6-sol"

Python OpenAI SDK

Đọc API key từ biến môi trường và truyền Base URL khi khởi tạo client. Thay giá trị model bằng một trong ba ID được chấp nhận khi cần.

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKEN_CODEX_API_KEY"],
    base_url="https://codex.anhlaptrinh.vn/v1",
)

response = client.chat.completions.create(
    model="GPT-5.6-sol",
    messages=[{"role": "user", "content": "Xin chào"}],
)
print(response.choices[0].message.content)

Node.js OpenAI SDK

Dùng thuộc tính baseURL của OpenAI client, giữ key trong environment và chọn một trong ba model được chấp nhận.

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKEN_CODEX_API_KEY,
  baseURL: "https://codex.anhlaptrinh.vn/v1",
});

const response = await client.chat.completions.create({
  model: "GPT-5.6-sol",
  messages: [{ role: "user", content: "Xin chào" }],
});
console.log(response.choices[0].message.content);

XỬ LÝ LỖI

Các lỗi thường gặp

401 Unauthorized

API key thiếu, sai hoặc đã bị thu hồi. Tạo lại key nếu cần.

404 Not Found

Kiểm tra Base URL phải kết thúc đúng một lần bằng /v1.

Model not found

Dùng đúng một trong ba ID: GPT-5.6-sol, GPT-5.6-terra hoặc GPT-5.6-luna; chú ý chữ hoa và chữ thường.
